creame un prompt para una ia de codigo para que cree una web para el pcbcience research club. este es un club dedicado a la investigacion cientifica y periodismo cientifico. para esto necesito que en el header se presente el logo de la organizacion(va estar el la carpeta), filtrar los articulos por categoria y un boton a otra web informativa sobre el club. esta web informativa va a tener informacion del club, mission, vision, significados de componentes y colores del logo , un slice show de fotos del programa y una seccion donde se presenta la directiva del club. En el body de la web principal se van a presentar los articulos cientificos en diferentes recuadros (como en national geographic), presentandose los articulos en orden cronologico. Tambien, crea una web aparte donde se pueda administrar los articulos para agragar y/o eliminar articulos insertando el archivo pdf, categoria, autor y portada o imagen. Incluye dentro de esta web de administracion, la posibilidad de modificar el slice show de fotos del programa y la seccion donde se presenta la directiva del club que aparecen en la web informativa sobre el programa.

Actúa como un desarrollador Full Stack senior especializado en HTML, CSS, JavaScript y Supabase.

Crea una plataforma web completa para el "PCB Science Research Club", una organización estudiantil dedicada a la investigación científica y el periodismo científico.

IMPORTANTE:
- Utilizar únicamente HTML, CSS y JavaScript Vanilla.
- No utilizar Node.js.
- Utilizar Supabase como backend y base de datos.
- Generar código limpio, modular, documentado y responsive.
- Diseñar una interfaz moderna inspirada en National Geographic, Scientific American y revistas científicas modernas.
- Utilizar una paleta profesional enfocada en ciencia, educación e investigación.
- Todo el contenido dinámico deberá cargarse desde Supabase.

====================================
WEB PRINCIPAL (INDEX)
====================================

Objetivo:
Mostrar los artículos científicos publicados por el club.

HEADER:
- Mostrar el logo oficial del club.
- El logo estará disponible dentro de la carpeta del proyecto.
- Mostrar nombre del club:
  "PCB Science Research Club".
- Menú de navegación responsive.
- Selector para filtrar artículos por categoría.
- Botón "Sobre el Club" que dirija a una segunda página informativa.
- Diseño elegante tipo revista científica.

BODY:
- Mostrar los artículos en formato de tarjetas similares a National Geographic.
- Cada tarjeta debe contener:
  - Imagen de portada.
  - Título.
  - Categoría.
  - Autor.
  - Fecha de publicación.
  - Resumen corto.
  - Botón "Leer Artículo".

ORDEN:
- Los artículos deben mostrarse automáticamente en orden cronológico descendente (más recientes primero).

AL ABRIR UN ARTÍCULO:
- Mostrar la información completa.
- Permitir visualizar el PDF integrado mediante visor PDF.
- Opción para descargar PDF.

FOOTER:
- Información del club.
- Redes sociales.
- Derechos reservados.

8. FOOTER
